# Archive

Historical release notes and one-off deploy instructions from earlier
FrameForge versions. They are kept for provenance only.

**Do not follow anything in this folder as current guidance.** Some of it is
contradicted by the shipping code, in particular:

- `NATIVE-OPTIMIZER.md` and `README.txt` quote path budgets directly. The only
  real budget lives in `shared/frameforge-limits.js`.
- `DEPLOY.txt` describes a Netlify deploy that was replaced by Cloudflare
  Pages. See `docs/deploy.md`.
- `APPLY-ME.txt` is the 7.5.0 hand-patch list, superseded by `CHANGELOG.md`.
- `VALIDATION.txt` is superseded by `docs/validation.md`.

Current documentation is `README.md`, `CHANGELOG.md`, and the rest of `docs/`.
