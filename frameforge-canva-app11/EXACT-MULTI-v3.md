# Exact multi-element silhouette v3

- Single SVG silhouettes remain one native Canva frame element.
- Multi-object raster silhouettes are inserted as aligned full-viewBox frame elements.
- Every object receives its own Canva 2048-byte path budget.
- All objects reuse one uploaded starter-photo asset.
- Decorative thin-line details are inserted beneath the native frames.
- Replacing one frame later does not automatically replace sibling frames; use the app flow again when one synchronized replacement is required.
