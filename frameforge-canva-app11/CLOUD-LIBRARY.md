# Live Cloudflare library

Paste the deployed Cloudflare Worker URL into the app panel and click **Refresh library**. Frames published from FrameForge appear without editing `mockups.json` or rebuilding the app.

The Worker URL is saved in this browser. Browsing and adding frames does not require publishing credentials. The optional admin token is required only for creator-side folder management, moving frames, and deletion. It is stored for the current browser session only; never share it with buyers or collaborators.

If fetches are blocked, allow the Worker hostname in the Canva Developer Portal's external/network URL settings and reload the preview.
