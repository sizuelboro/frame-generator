# Buyer compatibility test

Run this only on a disposable copy of the final template.

## Seller account

- [ ] Add the mockup from FrameForge.
- [ ] Ungroup if needed; lock only the overlay PNG.
- [ ] Leave the drop-target frame unlocked.
- [ ] Drop an uploaded photo onto the opening.
- [ ] Double-click and confirm crop/zoom/reposition controls.
- [ ] Use Replace and confirm the new photo remains clipped.
- [ ] Save, close, and reopen the design.
- [ ] Create the template link.
- [ ] Stop the local app server before buyer testing.

## Separate buyer account

- [ ] Open the template link without installing FrameForge.
- [ ] Use the template to create a new design.
- [ ] Drop an uploaded photo onto the opening.
- [ ] Double-click and adjust crop/zoom/reposition.
- [ ] Replace the image.
- [ ] Download a PNG and inspect the clipped edges.
- [ ] Close and reopen the buyer's design.
- [ ] Repeat on a Canva Free account if that is part of the sales promise.
- [ ] Repeat on mobile if mobile compatibility will be advertised.

## Pass condition

Advertise “works like a Canva frame” only if every promised account/device scenario above passes. Record the date, browser/app version, Canva plan, and a short screen recording as evidence.
